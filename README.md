# Dodge the Blocks
**Dodge the Blocks** is a simple and addictive arcade-style game built with Python and Pygame. The goal is to control a player block and avoid falling enemy blocks for as long as possible while trying to achieve the highest score.

## Gameplay

In **Dodge the Blocks**, blue square (the player) at the bottom of the screen. Red blocks fall from the top. Avoid getting hit by red blocks to survive and increase your score. The game ends immediately if the player collides with any falling red block.

## Controls
Left Arrow: Move player left
Right Arrow: Move player right
Close Window / Quit: Exit the game
