# Dodge the Blocks
**Dodge the Blocks** is a simple and addictive arcade-style game built with Python and Pygame. The goal is to control a player block and avoid falling enemy blocks for as long as possible while trying to achieve the highest score.

## Gameplay

In **Dodge the Blocks**, blue square (the player) at the bottom of the screen. Red blocks fall from the top. Avoid getting hit by red blocks to survive and increase your score. The game ends immediately if the player hits with any red block.
## Installation

1. Python 3.x is necessary.  
2. Install the Pygame library:
```bash
pip install pygame
```
3. Download or clone this repository.
4. Run the game:
```bash
python Dodgemame.py
```

## Controls
1. Left Arrow: Move player left
2. Right Arrow: Move player right
3. Close Window / Quit: Exit the game
